# --- torch: install the build that matches the machine -----------------------

# Apple-Silicon MPS, then CPU. Force one with  COPILOT_DEVICE=cpu|cuda|mps.
# It always runs on CPU if no accelerator wheel is installed, so `pip install
# torch==2.13.0` alone is a valid (slower) setup.
#
#   NVIDIA GPU (Linux/Windows):   CUDA 12.x wheel
#     pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu126
#   Apple Silicon (macOS arm64):  the default wheel already ships MPS -- nothing extra
#     pip install torch==2.13.0
#     (transformer ops without an MPS kernel fall back to CPU via
#      PYTORCH_ENABLE_MPS_FALLBACK=1, which _pick_device sets automatically)
#   CPU only (any OS, incl. final offline scoring):
#     pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
